# ITZFIZZ Scroll-Driven Hero Animation

A polished implementation of the ITZFIZZ web-development internship assignment.

## Stack

- React
- Vite
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger
- HTML / CSS / JavaScript

## Features

- Premium `WELCOME ITZFIZZ` hero
- Letter-by-letter entrance animation
- Staggered statistics
- Scroll-controlled sports-car visual
- `scrub: 1.5` smooth interpolation
- Transform-first animation
- Responsive desktop/mobile layout
- Reduced-motion CSS fallback
- GitHub Pages GitHub Actions deployment
- Full assignment documentation

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Read `DOCUMENTATION.md` for the requirement mapping, technical decisions, and deployment checklist.
